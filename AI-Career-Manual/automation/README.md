# AI 转型计划自动监督

## 已识别的 macOS 能力

- Calendar：安排固定学习时段
- Reminders：记录近期行动项
- Shortcuts：可将监督脚本包装为桌面或菜单栏快捷指令
- Notification Center：发送开始提醒和状态提醒
- `say`：可选语音提醒
- Kiro Hook：在工作区内手动触发计划检查

## 默认安排

- 周二 20:00–21:30：概念学习与知识卡
- 周四 20:00–21:30：官方文档与代码复现
- 周六 09:00–12:30：项目开发
- 周日 20:00–21:00：测试、复盘与下周计划

这些时段是初始默认值，可在 Calendar 中直接调整。

## 手动监督

在工作区根目录执行：

```bash
./AI-Career-Manual/automation/ai-career-status.sh
```

脚本会读取本工作区的首周任务清单，显示第一个未完成任务，并发送一条 macOS 通知。它不会读取日历、提醒事项、浏览记录或其他个人文件。

## 知识储备监督

监督不只检查项目任务，还检查“输入 → 知识卡 → 项目应用 → 周/月输出”：

- 每周至少 1 张有效知识卡；
- 每月 2 个架构案例复盘；
- 每月 1 份专题分析；
- 每天最多深读 1 篇材料，临时收件箱最多保留 20 条；
- 没有转化为知识卡或行动的收藏不计入成果。

## 监督规则

1. 每周只保留一个项目主目标和一个知识主题；
2. 每个学习时段结束必须留下代码、知识卡、文档或评测结果；
3. 周日复盘前同时检查项目任务和知识周计划；
4. 未完成任务只顺延当前任务，不新增学习方向；
5. Docker 缺失记录为环境风险，但不阻塞前期 Python 开发。
