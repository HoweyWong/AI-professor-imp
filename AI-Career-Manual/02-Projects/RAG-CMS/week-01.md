# RAG-CMS 首周任务清单

## 本周唯一主目标

跑通 CMS 文档问答的最小闭环：文档解析 → 切分 → 向量检索 → 模型回答。

## 任务

- [x] 第 1 天：完成工作区、项目 README 和环境记录
- [x] 第 2 天：创建 FastAPI 项目，完成一个健康检查接口和模型调用接口
- [ ] 第 3 天：实现 PDF、Markdown 或文本的文档解析，并保存解析结果
- [ ] 第 4 天：实现文本切分和元数据结构
- [ ] 第 5 天：接入 Embedding 与向量存储
- [ ] 第 6 天：完成检索、上下文拼接、回答和引用来源返回
- [ ] 第 7 天：准备 10 个测试问题，完成首周复盘

## 本周不做

- Agent
- Rerank
- 权限隔离
- 管理后台
- 多模型网关
- 本地模型部署

## 周末验收

至少有一个可运行接口、一个端到端问答案例、引用来源和 10 个测试问题记录。
