# AI-Career-Manual

AI 应用开发与架构转型工作区。

## 当前主线

以 CMS 技术文档智能问答系统（RAG-CMS）为第一个真实项目，逐步形成 Java 工程、AI 应用、工业业务和架构能力的复合优势。

## 目录

- `00-Inbox/`：临时收件箱
- `01-Knowledge-Cards/`：知识卡、知识储备计划与模板
- `02-Projects/`：项目代码与项目文档
- `03-Architecture-Cases/`：架构案例复盘
- `04-Industry-Reports/`：行业报告分析
- `05-Weekly-Reviews/`：周复盘与每日记录
- `06-Outputs/`：专题输出

## 当前环境

- Python 3.9.6
- Java 11.0.11
- Git 2.50.1
- Docker：未安装或未加入 PATH

## 执行检查

运行以下命令检查当前四条执行轨道与最近的 30/60/90 天阶段成果：

```bash
./automation/ai-career-status.sh --no-notify
```

脚本会同时显示：

- RAG-CMS 最新项目周计划；
- 最新知识周计划；
- 架构案例的 90 天进度和下一项；
- 行业报告的 90 天进度和下一项。
- 最近的阶段检查与专题输出截止日期。

架构案例从当周项目问题中提炼，原则上每周 1 篇；行业报告每月深读 1 份。两者都是当前主线的辅助产物，不新增并行项目。行业报告分析是输入，不能替代 `06-Outputs/` 中每月 2～3 页的专题输出。

`05-Weekly-Reviews/90-day-outcomes.md` 汇总 60 张有效知识卡、12 份一页知识周报、3 份专题分析、1 份个人 AI 架构能力地图、至少 3 条工作应用及 30/60/90 天检查。阶段成果是四条轨道的汇总验收，不是额外学习主线；脚本只提醒，仍需用户确认后才能勾选。
