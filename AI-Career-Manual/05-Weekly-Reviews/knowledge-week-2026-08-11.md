# 知识储备周计划｜2026-08-11 至 2026-08-17

## 本周唯一知识主题

RAG Ground Truth 设计：相关性、充分性与引用支持。

## 核心问题

如何描述“哪些内容相关”“哪些证据足以回答”以及“回答主张由什么来源支持”，避免单一 Recall 指标给出错误结论？

## 本周任务

- [x] 用自己的话区分相关 Chunk 集合与充分证据集合
- [x] 更新知识卡，补充充分证据命中指标和第 3、8 题实验
- [ ] 在 RAG-CMS 中完成四层评测报告：相关性、充分性、答案覆盖、引用忠实性
- [ ] 8月16日（周日）复盘：记录一个标注分歧案例和 Week 4 唯一知识主题

## 输入、处理与输出

```text
固定问题 + 相关 Chunk + 充分证据集合 + 答案要点 + 引用评分
→ Top-K 检索与人工判定
→ 集合 Recall + 充分证据命中 + 要点覆盖 + 引用忠实性
```

## 与 Java / Spring 的对照

- 相关 Chunk 类似候选记录集合，充分证据集合类似满足业务规则的最小条件组合；
- 数据校验类似 DTO / Bean Validation，指标计算类似领域 Service 纯函数；
- 边界是 Ground Truth 依赖人工判断，不能仅靠类型与规则保证语义正确。

## 本周不做

- 不扩展到自动裁判、模型微调或生产监控指标
- 不用阅读数量替代实际标注和参数实验
- 不在 Ground Truth 未稳定前优化检索或 Prompt

## 验收标准

至少完成一组“集合 Recall 低但充分证据已命中”的真实解释，并能将一个错误结果定位到标注、检索、生成或引用层。

## 周末滚动规则

复盘必须留下标注分歧、未解决问题和下一周唯一主题；用户确认后才更新勾选并创建下一周计划。
